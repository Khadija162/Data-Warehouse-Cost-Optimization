# Open usage dataset

`warehouse_usage.csv` is original synthetic data under the **CC0 1.0** public-domain dedication, generated deterministically by `python -m warehouse.data`. Three fictional warehouses (analytics, finance, experiments), 90 daily records each. These are **not actual Azure/Snowflake/Databricks charges**. The cost model is estimated compute hours times a fictional hourly rate; potential savings are an illustrative 50% of estimated idle cost, not validated savings. Dataset may be used as an openly reusable reproducible engineering fixture.
